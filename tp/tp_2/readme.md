# Travaux Pratiques 2 : DDD Tactique, Isolation de Persistance & Architecture Hexagonale
# Environnement cible : Windows (WampServer + Docker Desktop + Postman)
# Livrables attendus :Un dépôt Git contenant la modélisation sémantique des Contextes Bornés et l'infrastructure d'isolation de persistance.


# Objectifs

# 1. Appliquer les concepts stratégiques du DDD en isolant des langages ubiquitaires et des Contextes Bornés (Bounded Contexts).
# 2. Implémenter le pattern Database-per-Service en séparant physiquement les bases de données (MySQL et PostgreSQL).
# 3. Comprendre les contraintes de l'étanchéité des données (absence de clés étrangères et de jointures SQL inter-services).
